DEPLOYMENT CONFIGURATION TEMPLATE

After uploading files, update these configurations:

-------------------------------------------
FILE: config/database.php
-------------------------------------------

define('DB_HOST', 'YOUR_DB_HOST');           // e.g., localhost or sql123.infinityfree.net
define('DB_NAME', 'YOUR_DB_NAME');           // e.g., jmms_donations
define('DB_USER', 'YOUR_DB_USERNAME');       // Database username
define('DB_PASS', 'YOUR_DB_PASSWORD');       // Database password
define('DB_SOCKET', '');                     // Leave empty for online hosting

-------------------------------------------
FILE: config/razorpay.php
-------------------------------------------

define('RAZORPAY_KEY_ID', 'rzp_test_YOUR_KEY_ID');
define('RAZORPAY_KEY_SECRET', 'YOUR_KEY_SECRET');
